# Структура данных

В браузерной версии сервер не требуется. Чистая игровая логика находится в `game-core.js`, работа с интерфейсом — в `script.js`.

## Round

| Поле | Тип | Значение |
| --- | --- | --- |
| id | number | Последовательный номер раунда |
| player | string | `rock`, `scissors` или `paper` |
| computer | string | Независимый случайный выбор из тех же трёх значений |
| result | string | `win`, `loss` или `draw` с точки зрения игрока |
| date | string | Дата и время в формате ISO 8601 |

Камень побеждает ножницы, ножницы — бумагу, бумага — камень. Совпадающие ходы дают ничью. Все девять комбинаций проверяются unit-тестами.

## Statistics

`{ wins: 0, losses: 0, draws: 0, rounds: 0, winRate: 0 }`

`rounds = wins + losses + draws`. `winRate = wins / rounds * 100`; при нуле раундов процент равен 0. На экране процент округляется до одного десятичного знака, исходные расчёты не округляются. `addResult` возвращает новый объект, не изменяя предыдущую статистику.
